# My Diary

A clean, minimalist web application built with Python and Flask that allows users to maintain a private daily journal. This project features a dual-layout authentication system and a dedicated dashboard with a "crumbled paper" aesthetic for writing entries.
## ✨ Features

- **User Authentication:** Secure registration and login system using hashed passwords.
- **Sidebar Navigation:** An organized sidebar to view all previous entries by title and date.
- **Journaling Workspace:** A dedicated writing area with a texture for a classic diary feel.
- **Database Integration:** Persistent storage for users and diary entries using SQLite.


### Tech Stack
---

- **Backend** : Python, Flask
- **Database** : SQLAlchemy(SQLite)
- **Authentication:** Flask-Login, Werkzeug (for password hashing)
- **Frontend:** HTML5, CSS3 (Flexbox for responsive layouts)

# 🚀 Getting Started
---
1. **Prerequisites** 
>Bash

   pip install flask flask-sqlalchemy flask-login

2. **Installation** 

- Clone or download this repository to your local machine.
- Place your diary logo.avif in the static/ folder.
- 

>Bash
  
    python app.py

    The app will be available at http://127.0.0.1:5000
